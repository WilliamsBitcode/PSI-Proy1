Servicios

Nuestra metodología y servicios - Lo que aprenderas

  • Aprendizaje práctico desde el día 1: No solo teoría: cada clase construyes algo real. Desde tu primera página HTML hasta un portafolio completo.

  • Ritmo adaptado a ti: Clases inclusivas donde cada estudiante avanza a su propio ritmo, con apoyo personalizado.

  • Comunicación efectiva como eje: Aprendes a expresar tus ideas con claridad, a escuchar activamente y presentar tus proyectos con confianza.

  • Cultura ambiental y ética digital: Fomentamos el uso responsable de la tecnología, la optimización de recursos y la honestidad en el trabajo digital.

¿Qué aprenderas?

Contenido programado para los 2 años de estudio:

Habilidades y capacidades Año 1

Trabajo colaborativo - Google Suite

Google Suite

Aprenderás el uso y administración de recursos en línea, así como el trabajo colaborativo en la nube, para realizar coordinaciones sincrónicas como asincrónicas.

Diseño de interfaces - Figma

Figma

Aprenderás a diseñar prototipos de interfaces de usuario de alta fidelidad, componentes, estilos, sistemas de diseño, desde el wireframe hasta el mockup interactivo.

Estructura y Maquetación - HTML5

HTML5

Aprenderás a estructurar el contenido web con etiquetas semánticas, formularios, multimedia y accesibilidad, sentando las bases de toda página web.

Diseño visual y Estilos web - CSS3

CSS3

Dominarás la estética y el diseño responsivo, aplicando colores, tipografías, layouts con Flexbox y Grid, animaciones y transiciones para crear experiencias visuales impactantes.

Programación e interacción - JavaScript

JavaScript

Dotarás de vida a tus páginas con lógica de programación, manipulación del DOM, eventos, funciones y más, logrando interacciones dinámicas y funcionales.

Capacidades y competencias Año 2

Básico en Redes y conectividad

Redes y Conectividad

Comprenderás los fundamentos de redes informáticas: protocolos, direccionamiento IP, topologías, y principios de seguridad básica.

Lógica de programación - PSeInt

PSeInt - Lógica y Algoritmos

Desarrollarás pensamiento lógico mediante pseudocódigo y diagramas de flujo, aprendiendo estructuras de control, variables y más.

Modelamiento de BD - DrawIO/WorkBench

DrawIO / WorkBench

Aprenderás a diseñar modelos entidad-relación y diagramas lógicos de bases de datos, asi como a planificar estructuras de datos eficientes y normalizadas.

Gestión y manejo de BD - MySQL

MySQL

Implementarás bases de datos relacionales, creando tablas, relaciones y consultas SQL (SELECT, INSERT, UPDATE, DELETE). Aprenderás a optimizar consultas y mantener la integridad de los datos.

Programación BackEnd - PHP

PHP - Backend

Desarrollarás la lógica del servidor: manejo de formularios, conexión a MySQL, sesiones, autenticación y generación de contenido dinámico para aplicaciones web completas.
